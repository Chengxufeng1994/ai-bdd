## Context / Problem

訪客臨停目前無法計費，訪客車位常被外部車輛長時間占用。 ← PRD §1

## Personas

**這個 feature 為誰做**：P-1（訪客）。P-2 出現在流程裡但不是這次的受益者 ← 推論

### P-1  訪客

**是誰**：不在月租名單上的任何一台車 ← Q-1
**怎麼取得這個身分**：入口抽紙票 ← PRD §2
**跟誰容易混**：跟月租戶靠有沒有感應卡分辨 ← PRD §2
**他要什麼**：出場前知道要付多少、付得掉 ← 推論

### P-2  月租戶

**是誰**：名單上且未到期的車 ← PRD §2
**怎麼取得這個身分**：感應卡 ← PRD §2
**跟誰容易混**：與「住戶」不完全相同——住戶不一定有月租車位 ← 推論
**他要什麼**：進出不要被擋 ← 推論

## Goals / Non-Goals

### Goals

- 讓訪客離場前完成付款，把長時間占位的外部車輛擋在外面 ← PRD §1
- 訪客計費與出場放行 ← PRD §2

### Non-Goals

- 月租費線上收款 —— 不做：帳務接在社區總帳上 ← Q-1
- 機車計費 —— 延後：機車格沒有柵欄，日後要收費是另一次發包 ← Q-3

接受的風險：
- 不做月租證掛失名單管理，因此擋不住已作廢的月租證繼續感應出入 ← 推論
- 機車格沒有柵欄，日後要收費是另一次發包 ← Q-3

## User Stories

### US-1 · visitor-billing

**優先級**：P1 —— 這個 feature 要解的就是訪客計費 ← PRD §1
身為 P-1（訪客），我想在出場前知道要付多少，以便付完就能開走 ← 推論

涵蓋 FR-1。沿規則切：訪客計費是一條獨立成立的規則，自己可驗收。

#### FR

**FR-1**  When 訪客車出場, the system shall 依停留時長計費，前 30 分鐘免費。 ← PRD §3
- **AC-1.1**  停 29 分 → 收 0 元 ← PRD §3
  - Given 一台訪客車已入場並抽了紙票
  - When 它在入場後 29 分鐘於繳費機結帳
  - Then 應收金額是 0 元
- **AC-1.2**  停剛好 30 分 → 收 0 元 ← Q-4
  - Given 一台訪客車已入場並抽了紙票
  - When 它在入場後 30 分鐘整於繳費機結帳
  - Then 應收金額是 0 元
- **AC-1.3**  停 31 分 → 收 30 元 ← PRD §3
  - Given 一台訪客車已入場並抽了紙票
  - When 它在入場後 31 分鐘於繳費機結帳
  - Then 應收金額是 30 元

### US-2 · monthly-pass

**優先級**：P2 —— 月租戶不計費是讓訪客計費上線時不誤收住戶的錢 ← PRD §4
身為 P-2（月租戶），我想刷卡就直接出去，以便不用每次都停下來付款 ← 推論

涵蓋 FR-2、FR-3。沿規則切：月租戶出場是另一條獨立成立的規則，自己可驗收；跟訪客計費的關聯只在判斷身分時用到 FR-1，所以用「另外依賴」宣告，不搬過來。

**另外依賴**：FR-1（定義在 US-1 底下）——月租證過期的車不是 P-2，走訪客計費那條路

#### FR

**FR-2**  When 月租戶刷卡出場, the system shall 直接開啟柵欄，不計費。 ← PRD §4
- **AC-2.1**  名單內且未到期 → 開柵欄，金額 0 ← PRD §4
  - Given 一台月租車在名單內且未到期
  - When 它刷卡出場
  - Then 柵欄開啟且應收金額是 0 元

**FR-3**  When 火警警報啟動, the system shall 開啟出場柵欄並保持開啟到警報解除，期間不計費。 ← Q-2
- **AC-3.1**  警報中訪客車出場 → 柵欄已開，金額 0 ← Q-2
  - Given 火警警報已啟動且尚未解除
  - When 一台訪客車駛向出場柵欄
  - Then 柵欄保持開啟且應收金額是 0 元

#### NFR

**NFR-1**  出場柵欄自刷卡到開啟不超過 2 秒 ← 推論

#### Q

（空）——紅卡都答了，各自長成了規則
