## Context / Problem

借書全靠櫃台手寫登記本，逾期的書沒有人追，熱門的書常被同一人借走好幾個月。 ← PRD §1

## Goals / Non-Goals

### Goals

- 讓每一本借出的書都有明確的到期日，到期沒還的看得出來 ← PRD §1
- 到期日與續借 ← PRD §2

### Non-Goals

- 逾期罰款 —— 不做：罰款歸縣府的收費系統 ← Q-1
- 期刊與視聽資料 —— 延後：還沒建檔，建檔後另一次做 ← Q-3

接受的風險：
- 不另外同步讀者證停用名單，因此擋不住已停用的讀者證繼續上網續借 ← 推論
- 期刊與視聽資料這段期間仍靠手寫登記本 ← Q-3

## User Stories

### US-1 · due-date

**優先級**：P1 —— 這個 feature 要解的就是借出去的書沒有到期日 ← PRD §1
身為 P-1（讀者），我想借書時就知道哪天要還，以便不會不小心逾期 ← 推論

涵蓋 FR-1。沿規則切：到期日怎麼算是一條獨立成立的規則，自己可驗收。

#### FR

**FR-1**  When 館員借出一本書, the system shall 把到期日定為借出當天加 14 天，遇休館日順延到下一個開館日。 ← PRD §3、Q-4
- **AC-1.1**  週四借出 → 到期日是兩週後的週四 ← PRD §3
  - Given 一位讀者持有效讀者證，2026-10-08 不是休館日
  - When 館員在 2026-09-24 借給他一本書
  - Then 到期日是 2026-10-08
- **AC-1.2**  第 14 天剛好休館 → 順延一天 ← Q-4
  - Given 一位讀者持有效讀者證，2026-10-10 國慶日休館、2026-10-11 開館
  - When 館員在 2026-09-26 借給他一本書
  - Then 到期日是 2026-10-11
- **AC-1.3**  順延後又碰上休館 → 順延到第一個開館日 ← Q-4
  - Given 一位讀者持有效讀者證，2026-10-10 國慶日、2026-10-11 盤點、2026-10-12 週一都休館
  - When 館員在 2026-09-26 借給他一本書
  - Then 到期日是 2026-10-13

### US-2 · renewal

**優先級**：P2 —— 續借是讓到期日上線後讀者不必為了延期專程跑一趟 ← PRD §4
身為 P-1（讀者），我想在到期前自己上網續借，以便不必為了延期專程跑一趟 ← 推論

涵蓋 FR-2、FR-3。沿規則切：續借是另一條獨立成立的規則，自己可驗收；跟到期日的關聯只在算新到期日時用到 FR-1，所以用「另外依賴」宣告，不搬過來。

**另外依賴**：FR-1（定義在 US-1 底下）——續借後的新到期日同樣遇休館日順延

#### FR

**FR-2**  When 讀者在到期日前申請續借, the system shall 把到期日從原到期日再延 14 天，每本書限續借一次。 ← PRD §4
- **AC-2.1**  到期前第一次續借 → 到期日延 14 天 ← PRD §4
  - Given 讀者借的一本書到期日是 2026-10-08、還沒續借過，名下沒有逾期的書
  - When 他在 2026-10-06 上網申請續借
  - Then 續借成功，到期日變成 2026-10-22

**FR-3**  When 名下有逾期未還的書的讀者申請續借, the system shall 拒絕續借，直到逾期的書都還了。 ← Q-2
- **AC-3.1**  有一本逾期 → 另一本也不能續借 ← Q-2
  - Given 讀者名下一本書已逾期未還，另一本到期日是 2026-10-08、還沒續借過
  - When 他在 2026-10-06 上網申請續借那本還沒到期的書
  - Then 續借被拒，那本書的到期日仍是 2026-10-08

#### NFR

**NFR-1**  續借申請送出後 2 秒內顯示新的到期日 ← 推論

## 原文

館長 2026-09-09 帶來的一頁需求，逐字；§ 編號是記錄時加的。

§1 現在借書全靠櫃台手寫登記本，逾期的書沒有人追，熱門的書常被同一個人借走好幾個月，其他讀者借不到。
我們要讓每一本借出去的書都有明確的到期日，到期沒還的看得出來。
§2 讀者用讀者證借書；讀者證是縣裡統一發的，持有效讀者證的才能借。
這次要做的是到期日跟續借，罰款怎麼收先不動。
§3 每本書借期兩週，從借出那天算。還書在櫃台刷書，刷了就算還了。
本館每週一固定休館，國定假日也休館。
§4 讀者可以在到期前自己上網續借一次，從原本的到期日再給兩週。
§5 不做自助借還書機，去年館務會議否決了。館裡的網路只連縣網，不能接外部服務。
讀者證系統是縣裡的、已經上線，借書要沿用它驗讀者證，不另起一套帳號。
§6 有書逾期沒還的人，續借好像要擋（館長說總館規章有規定，但不確定內容）。
