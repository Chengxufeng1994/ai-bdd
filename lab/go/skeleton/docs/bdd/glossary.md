# Glossary

**更新於**: 2026-08-19

跨 feature 的共用規則與詞彙。各份 map 只回指編號，**不複製內容**。
角色名稱定義在 `actor.md`，這裡不重複。

---

## 詞彙

| 詞 | 定義 | 為什麼要定義 |
| --- | --- | --- |
| **訓練（session）** | 使用者明確開始、明確結束的一段紀錄，內含數個動作 | 需求說「每次進健身房」，但那是場所不是資料邊界 |
| **動作（exercise）** | 動作庫裡的一個項目，例如「槓鈴臥推」。有型別 | |
| **組（set）** | 一個動作底下的一次執行，含重量與次數 | 需求說「幾組、多重、幾下」，三者的層級關係要固定 |
| **有效重量** | 算容量時實際採用的重量。由動作型別決定，**不等於**使用者填在重量欄的數字 | 這個詞是為了讓自體重與輔助型動作有地方放，見 Shared 4 |
| **容量（volume）** | 有效重量 × 次數。單位「公斤·次」 | 需求說「總容量是公認指標」但沒定義 |
| **同期** | 上一週的第 1 到第 N 天，N ＝ 本週已過的天數（含今天） | 見 Shared 8 |

## 共用規則

### Shared 1. 容量的定義
一組的容量 ＝ 有效重量 × 次數。一次訓練的總容量 ＝ 所有**計入**的組的容量總和。
單位是公斤·次，不是公斤。

用於：`session-training-volume`、`workout-history`、`week-over-week-progress`、
`edit-a-logged-workout`

### Shared 2. 訓練的歸屬日
一次訓練歸屬於**開始時間**所在的當地日期，跨午夜不切分。歸屬日在訓練開始的當下
凍結，之後使用者換時區也不改變。

用於：`log-a-workout`、`workout-history`、`week-over-week-progress`

### Shared 3. 重量的儲存與顯示
一律以公斤儲存。依使用者設定的顯示單位（公斤或磅）換算後顯示，四捨五入到小數點
後一位。切換單位只改顯示，不改已存的值，來回切換不得讓數值漂移。

用於：`log-a-workout`、`session-training-volume`、`workout-history`

### Shared 4. 動作型別決定怎麼計量與有效重量

| 型別 | 使用者填什麼 | 計量 | 有效重量 | 例 |
| --- | --- | --- | --- | --- |
| 負重型 | 重量、次數 | 次數 | 填的重量 | 槓鈴臥推 |
| 自體重型 | 次數 | 次數 | 使用者體重 | 伏地挺身 |
| 自體重加負重型 | 額外加掛的重量、次數 | 次數 | 體重 ＋ 加掛 | 負重引體向上 |
| 輔助型 | 輔助配重、次數 | 次數 | 體重 − 輔助配重 | 輔助引體向上機 |
| **計時型** | 秒數（重量選填） | 秒數 | — 不計容量 | 棒式 |
| **距離型** | 重量、距離 | 距離 | — 不計容量 | 農夫走路 |

前四種以次數計量，容量算得出來。後兩種**完整記錄但對總容量的貢獻是 0**，
並套用 Shared 9 的標示。

← `session-training-volume/questions/timed-and-distance-exercises.md`

用於：`session-training-volume`、`custom-exercise-library`

### Shared 5. 熱身組
標記為熱身的組**完整記錄**（看得到重量與次數），但**不計入任何總容量**——
這次的、當日的、當週的都不計。

用於：`log-a-workout`、`session-training-volume`、`week-over-week-progress`

### Shared 6. 單邊動作
單邊動作的次數欄填**單邊**的次數，算容量時自動 ×2。畫面顯示「8 下 ×2 邊」——
那個乘法必須看得見，否則使用者無從驗證。

用於：`log-a-workout`、`session-training-volume`

### Shared 7. 週的定義
一週從當地時間週一 00:00 起算的日曆週。

用於：`week-over-week-progress`、`workout-history`

### Shared 8. 同期比較
比較兩週時，兩邊都取「該週的第 1 到第 N 天」，N ＝ 本週已過的天數（含今天）。
週日時 N＝7，等於整週對整週。

理由：拿「完整的上週」比「還沒過完的本週」，週一到週五永遠顯示退步——那個負數
不是進步的訊號，是日期的訊號。

用於：`week-over-week-progress`

### Shared 9. 未計入的動作要在畫面上標示
有動作因為算不出容量而未計入總容量時，畫面要標示「N 個動作未計入」，N 是該次
訓練中未計入的**相異動作數**。兩種情況會觸發：需要體重但沒有體重紀錄
（`session-training-volume` Rule 5），以及計時型與距離型（同 Rule 8）。

沒有這個標示，使用者看到的總容量會比他實際做的少，而畫面上沒有任何線索。
所以標示是規則的一部分，不是提示文案。

用於：`session-training-volume`、`week-over-week-progress`
