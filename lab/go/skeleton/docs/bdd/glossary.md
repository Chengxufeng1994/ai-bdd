# Glossary

**更新於**: 2026-09-02

跨 story 共用的詞彙（ubiquitous language）。**不放規則**——規則就近寫在對應
`.feature` 的 `Rule:` 裡，跨 story 共用的規則就在最早定義它的那個 `.feature`

角色名稱定義在 `actor.md`，這裡不重複。

## 詞彙

| 詞 | 定義 | 為什麼要定義 |
| --- | --- | --- |
| **訓練（session）** | 使用者明確開始、明確結束的一段紀錄，內含數個動作 | 需求說「每次進健身房」，但那是場所不是資料邊界 |
| **動作（exercise）** | 動作庫裡的一個項目，例如「槓鈴臥推」。有型別 | |
| **組（set）** | 一個動作底下的一次執行，含重量與次數 | 需求說「幾組、多重、幾下」，三者的層級關係要固定 |
| **有效重量** | 算容量時實際採用的重量。由動作型別決定，**不等於**使用者填在重量欄的數字 | 這個詞是為了讓自體重與輔助型動作有地方放，見 `session-training-volume.feature` Rule 2、Rule 8 |
| **容量（volume）** | 有效重量 × 次數。單位「公斤·次」 | 需求說「總容量是公認指標」但沒定義，見 `session-training-volume.feature` Rule 1 |
| **同期** | 上一週的第 1 到第 N 天，N ＝ 本週已過的天數（含今天） | 見 `week-over-week-progress.feature` Rule 2 |
