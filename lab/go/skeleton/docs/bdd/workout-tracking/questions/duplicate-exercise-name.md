# 新增的動作跟已經有的同名怎麼辦？

**狀態**: 已答 · **輪次**: 2 · **信心**: 中 · **story**: custom-exercise-library · **面向**: 重複

## 選項
1. 同一使用者的動作庫內名稱唯一（去頭尾空白、大小寫、全半形正規化後比對）；與內建動作同名時擋下並建議改用內建的
2. 允許同名，用建立時間區分
3. 只擋完全一樣的字串，正規化不做
4. 允許同名但自動加序號（「臥推 (2)」）
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
同名動作的代價落在**歷史紀錄與週比較**上：兩個「臥推」會讓「我的臥推有沒有進步」
永遠算不對，而使用者看不出畫面上那兩個一模一樣的名字是兩個東西。

選項 3 不做正規化等於沒擋——「臥推」與「臥推 」（尾端一個空白）是使用者完全無法
分辨的兩筆。全半形要一起正規化，是因為中文輸入法會混進全形括號。

選項 4 的自動序號把問題丟回給使用者，而他當初打同一個名字就是因為他覺得那是同一個
東西。

## 影響的規則
`custom-exercise-library` Rule 3
