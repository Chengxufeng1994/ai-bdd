# 刪除一次訓練要不要能反悔？

**狀態**: 已答 · **輪次**: 3 · **信心**: 中 · **story**: edit-a-logged-workout · **面向**: 時限

## 選項
1. 刪除前二次確認，確認後直接刪掉，不可復原
2. 軟刪除，30 天內可從垃圾桶復原
3. 直接刪，不確認（誤刪就重記）
4. 不提供刪除，只能改
5. 不知道／先跳過

## 答案
選 1。**確認是介面行為，不是伺服器狀態**——不建立「待確認的刪除」這種東西。

## 為什麼
選項 2 比較貼心，但它會長出垃圾桶畫面、保留期規則，以及一個很煩的問題：被軟刪除
的訓練算不算進週比較？（不算，但它還在資料裡，於是每個查詢都要記得過濾——
漏掉一處就是一個很難查的 bug。）

在這份需求裡，一次訓練的重建成本是「照著記憶重打十來組」，不是不可挽回。
二次確認擋掉的是誤觸，那是主要風險。

**「確認是介面行為」那一句是刻意補的**：如果把「要求刪除」做成伺服器上的一筆
待確認紀錄，就會多出「它會不會過期」「別的裝置看不看得到」兩個沒人問過的問題。
所以規則只約束「刪除本身不可復原」與「刪除前要看得到摘要」，不約束確認流程。
