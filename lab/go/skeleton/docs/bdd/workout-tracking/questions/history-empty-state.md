# 一筆紀錄都沒有的時候顯示什麼？

**狀態**: 已答 · **輪次**: 2 · **信心**: 高 · **story**: workout-history · **面向**: 空與零

空與零面向的追問。

## 選項
1. 顯示引導文案與「開始第一次訓練」的入口，不顯示空表格
2. 顯示空的表格，只有表頭
3. 顯示範例資料，標示為範例
4. 直接把使用者導去記錄畫面
5. 不知道／先跳過

## 答案
選 1。查詢本身**成功**並回一個空清單，不是失敗、不是找不到。

## 為什麼
選項 3 的範例資料會流進總容量與週比較（或者要處處記得排除它），為了一個第一天的
畫面污染所有計算。

選項 4 讓使用者無法瀏覽這個頁面確認自己在哪。

「成功且為空」那一句是刻意補的：沒資料時回錯誤、還是回空清單，是兩種完全不同的
實作，而畫面上長得一樣。

## 影響的規則
`workout-history` Rule 4
