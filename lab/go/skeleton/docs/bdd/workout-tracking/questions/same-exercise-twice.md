# 同一個動作在一次訓練裡做兩輪，算幾個動作？

**狀態**: 已答 · **輪次**: 2 · **信心**: 高 · **story**: log-a-workout · **面向**: 重複

臥推 3 組 → 划船 3 組 → 回頭再臥推 2 組。

## 選項
1. 畫面上是兩個獨立的區塊，容量照樣全部加總
2. 自動合併成一個臥推區塊，共 5 組
3. 擋下，同一動作只能出現一次，請使用者接在原本的區塊後面
4. 兩個區塊，但總容量只算第一個區塊
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 的合併會改變順序資訊——使用者記錄的順序就是他做的順序，合併之後
「先練什麼」這件事消失了。

選項 4 明顯錯，列出來是為了確認選項 1 的「容量全部加總」是刻意的，不是漏想。

## 影響的規則
`log-a-workout` Rule 5
