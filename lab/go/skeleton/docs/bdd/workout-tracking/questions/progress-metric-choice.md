# 使用者到底靠什麼判斷「有沒有進步」？

**狀態**: 已答 · **輪次**: 1 · **信心**: 低 · **story**: week-over-week-progress · **面向**: 降級

需求把「總容量是公認衡量訓練量的主要指標」當成既定事實陳述。這一題在質疑那個
前提——不是質疑它對不對，是質疑**它要拿來比什麼**。

## 選項
1. 只做週總容量，一個數字
2. 週總容量 ＋ 訓練次數（天數）
3. 週總容量 ＋ 各動作的最高重量
4. 估算 1RM（Epley 公式）為主，總容量為輔
5. 不知道／先跳過

## 答案
選 2。信心低。

## 為什麼
先講為什麼要問：總容量會在兩種情況下說謊。**一、練少但練重**——重量進步、次數
減少，總容量下降；使用者其實變強了，App 告訴他退步。**二、多練一天**——總容量
上升，但那是頻率變了不是能力變了。需求說總容量是「主要指標」，可是主要指標的
用途是比較，而這兩種情況下它比出來的東西是錯的。

選 2（加上訓練次數）是最小的修補：它讓第二種情況變得看得出來——容量 +20% 但天數
從 2 天變 3 天，使用者自己會判斷。它不需要新公式，也不需要新資料。

選項 3 與 4 才真正解決第一種情況，但它們是**另一則 story**：最高重量與 1RM 要以
動作為單位比較，那需要「我的臥推史」那條線（見
`workout-history/questions/history-scope-and-order.md` 的選項 4）。

信心低，而且低得該讓人不安：**「靠什麼判斷進步」是使用者研究的問題，不是我能
代答的**。這一題的答案只決定本階段做什麼，沒有驗證那個前提。建議做完之後拿真實
使用者驗一次。
