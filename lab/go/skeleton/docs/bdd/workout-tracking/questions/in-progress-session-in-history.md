# 還沒結束的訓練會出現在歷史裡嗎？

**狀態**: 已答 · **輪次**: 3 · **信心**: 高 · **story**: workout-history · **面向**: 邊界

`log-a-workout` Rule 2 說訓練不會自動結束，所以「進行中」可能持續好幾天。

## 選項
1. 不進歷史清單，另外在頂端顯示「有一筆訓練進行中」，可點進去繼續
2. 進歷史清單，跟已結束的混在一起
3. 進歷史清單但標示為進行中
4. 進行中的訓練完全不顯示，直到結束
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
歷史是拿來回顧的，進行中的那筆是拿來繼續的——兩種用途。混在一起（選項 2、3）
會讓「最近一次訓練的總容量」這個數字有時候指向一筆還沒做完的訓練。

選項 4 會讓使用者找不到自己忘了結束的那筆，然後被 `log-a-workout` Rule 1 的
「已有進行中的訓練」擋住卻不知道為什麼。

## 影響的規則
`workout-history` Rule 5
