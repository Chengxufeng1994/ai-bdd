# 已經被訓練紀錄用過的自訂動作，可以刪掉或改名嗎？

**狀態**: 已答 · **輪次**: 2 · **信心**: 中

## 選項
1. 被引用過的不能刪，只能封存（不再出現在挑選清單，歷史仍看得到）；改名允許，且套用到所有歷史
2. 可以刪，歷史紀錄裡的那些組跟著消失
3. 可以刪，歷史紀錄保留動作名稱的字串快照
4. 都不能改，動作一旦建立就固定
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會讓刪一個動作連帶改變過去的總容量，而使用者以為自己只是在整理動作庫。

選項 3（字串快照）避開了那個問題，但它會讓改名之後歷史顯示舊名字——於是
「我的臥推史」被切成兩半，而改名的動機通常正好是想把它們合起來。

封存與刪除的分界落在**有沒有被引用**：沒引用過的直接刪（沒有任何後果），
引用過的只能封存。這條界線可機械判定，不用問使用者。

## 影響的規則
`custom-exercise-library` Rule 4、Rule 5
