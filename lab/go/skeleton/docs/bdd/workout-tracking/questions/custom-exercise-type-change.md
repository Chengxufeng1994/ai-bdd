# 建立自訂動作時要不要選型別？選錯了可以改嗎？

**狀態**: 已答 · **輪次**: 3 · **信心**: 中

`Shared 4` 讓型別決定容量怎麼算，所以自訂動作一定要有型別。

## 選項
1. 建立時必選，預設負重型；被引用之後不可再改型別，只能建新的並封存舊的
2. 建立時必選，隨時可改
3. 不選，一律當負重型
4. 不選，系統從有沒有填重量自動推斷
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 的「隨時可改」跟 `edit-scope-and-recompute` 的即時重算撞在一起：把一個用過
三個月的動作從負重型改成自體重型，**過去三個月的總容量會全部改變**，而使用者
只是覺得自己修好了一個分類錯誤。

選項 4 的自動推斷會把「忘記填重量」跟「這是自體重動作」搞混——而這兩者在資料上
長得一模一樣。

預設負重型是因為它涵蓋絕大多數器材，而且它是唯一不需要體重就能算的型別。

## 影響的規則
`custom-exercise-library` Rule 2、Rule 6
