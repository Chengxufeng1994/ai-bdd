# 失敗組（推不起來，0 下）怎麼記？

**狀態**: 已答 · **輪次**: 2 · **信心**: 中

## 選項
1. 允許填 0 下，容量貢獻 0，但仍計入組數
2. 擋下，0 下的組不成立，請使用者直接不要記
3. 允許 0 下，且該組完全不計入（組數也不算）
4. 另外做一個「失敗」標記，次數欄仍要填實際完成數
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會讓使用者失去「我今天在這個重量上卡關了」這個資訊，而那恰好是判斷要不要
減重量時最有用的一筆。

選項 4 多一個概念，但它能表達的事（「做了 3 下然後失敗」）用選項 1 加一組 3 下
也能表達。留在三個以下的概念裡。

## 影響的規則
`log-a-workout` Rule 3
