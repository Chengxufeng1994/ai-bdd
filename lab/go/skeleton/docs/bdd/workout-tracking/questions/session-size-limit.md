# 一次訓練最多幾個動作、幾組？

**狀態**: 已答 · **輪次**: 3 · **信心**: 低

規模面向的追問。

## 選項
1. 單次訓練最多 50 個動作、單一動作最多 20 組，超過擋下並提示
2. 不設限
3. 不設硬上限，超過一定量時警告但仍允許
4. 依方案分級（免費版較少）
5. 不知道／先跳過

## 答案
選 1，信心低。

## 為什麼
信心低是誠實的：50 與 20 沒有來源，是憑常識訂的。但**不設限（選項 2）比訂錯
數字更糟**——不設限等於沒有人想過這件事，而第一個把手指按住「新增組」不放的
使用者會發現。

選項 4 牽涉收費方案，這份需求沒有任何收費敘述，不該由這裡引進。

## 影響的規則
`log-a-workout` Rule 8
