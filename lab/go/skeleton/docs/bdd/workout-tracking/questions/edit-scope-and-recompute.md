# 已經記完的訓練可以改嗎？改了之後歷史容量跟著變嗎？

**狀態**: 已答 · **輪次**: 2 · **信心**: 中 · **story**: edit-a-logged-workout · **面向**: 時間

需求說「常常漏記」，那就一定會有事後補記與更正。

## 選項
1. 可改任何欄位；所有彙總（總容量、歷史、週比較）一律以當前資料即時重算
2. 可改，但已經算出來的總容量存成快照不動
3. 只能改當天的，過去的鎖住
4. 不能改，只能刪掉重記
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會讓同一頁上出現兩個矛盾的數字：明細加起來是 1520，標題寫 1480。
使用者沒有任何方法知道哪個是對的。

選項 3 的「當天」界線會直接卡到需求說的漏記情境——想起來昨天忘了記的人剛好被擋
在外面。

後果要說清楚：**過去的週比較會因為補記而改變**。這是對的行為（資料本來就補齊
了），但如果之後有「連續天數」之類的東西，它們得能承受回溯變動。現在沒有，記下來。

## 影響的規則
`edit-a-logged-workout` Rule 1、Rule 2
