# 上週同期沒有紀錄時顯示什麼？

**狀態**: 已答 · **輪次**: 2 · **信心**: 高 · **story**: week-over-week-progress · **面向**: 空與零

空與零面向。分兩種：完全沒有上一週（第一週），與有上一週但同期是 0。

## 選項
1. 兩種都不顯示百分比，各自給一句話：「這是你的第一週」／「上週同期沒有紀錄」
2. 顯示 +100%
3. 顯示 +∞ 或「—」
4. 把上週當 0 算，顯示本週的絕對數字加一個向上的箭頭
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 的 +100% 是除以零之後最常見的謊話：它跟「上週 6000、本週 12000」顯示的
東西一模一樣，但意思完全不同。

選項 4 的向上箭頭同理——從沒練到有練不是「進步 100%」，它沒有比例可言。

分成兩句話而不是一句，是因為兩件事對使用者的意義不同：第一週是「還不能比」，
上週同期 0 是「你上週這幾天沒練」——後者本身就是有用的資訊。

## 影響的規則
`week-over-week-progress` Rule 4、Rule 5
