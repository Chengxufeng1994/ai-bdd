# 一次「訓練」從哪裡開始、到哪裡結束？

**狀態**: 已答 · **輪次**: 1 · **信心**: 高

需求說「每次進健身房」，但 App 不知道使用者進沒進健身房。要有一個資料上的邊界。

## 選項
1. 使用者明確按「開始訓練」與「結束訓練」
2. 記下第一組時自動開始，30 分鐘沒有新動作就自動結束
3. 不需要邊界，每一組各自帶時間戳，用日期把當天的組聚起來
4. 使用者只按「結束」，開始時間取第一組的時間
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會讓**系統變成一個 actor**——「自動結束」這個動作的主詞不是任何人。
那會長出一整組沒人問過的規則：結束前要不要提醒？結束後還能不能補記？
在還沒有任何需求支持的情況下，這是憑空多出來的複雜度。

選項 3 看起來更簡單，但「這次的總容量」就沒有「這次」可指——需求裡最重要的
那個數字會失去定義。

## 影響的規則
`log-a-workout` Rule 1、Rule 2；連帶決定 `actor.md` 不列「系統」
