# 輔助配重比體重還重的時候呢？

**狀態**: 已答 · **輪次**: 3 · **信心**: 高 · **story**: session-training-volume · **面向**: 邊界

輔助型的有效重量是「體重 − 輔助配重」。體重 70、輔助 75 會得到 −5。

## 選項
1. 有效重量以 0 為下限，該組容量 0，並在畫面提示
2. 讓它是負的，總容量因此減少
3. 擋下，不允許輔助配重大於體重
4. 取絕對值
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會讓「多做幾下」變成「總容量更低」，那個方向是反的。

選項 3 看起來合理，但輔助引體的配重片是實體的，使用者確實可能掛上超過自己體重的
配重（機器不會阻止他）。擋下等於要求使用者說謊或不記。

選項 4 更糟：容量會隨著輔助加重而增加。

## 影響的規則
`session-training-volume` Rule 2（Example 2.5）
