# 同一天練兩次算一次還是兩次？

**狀態**: 已答 · **輪次**: 2 · **信心**: 高

早上練腿、晚上練胸的人不少。

## 選項
1. 兩筆獨立的訓練，各自有自己的總容量；當日／當週彙總時加總
2. 合併成一筆，第二次接在第一次後面
3. 兩筆，但當日彙總只取容量較高的那一筆
4. 擋下，一天只能記一次
5. 不知道／先跳過

## 答案
選 1。

## 為什麼
選項 2 會跟 `session-boundary` 的答案打架——使用者已經明確按了兩次「開始」。
選項 3 的「只取較高」會讓**當日總容量小於當日各次容量之和**，那是使用者按
計算機一加就會發現不對的那種數字。

## 影響的規則
`log-a-workout` Rule 7
