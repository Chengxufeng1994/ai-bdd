# 沒有重量的動作（伏地挺身、引體向上）容量怎麼算？

**狀態**: 已答 · **輪次**: 1 · **信心**: 中 · **story**: session-training-volume · **面向**: 空與零

需求說「每組多重、做幾下」，隱含每一組都有重量。伏地挺身撞破這個假設。

## 選項
1. 重量欄留空，這些動作不計入總容量
2. 使用者自己在重量欄填一個數字（想填體重就填體重），系統不管它是什麼
3. 動作分型別，型別決定「有效重量」怎麼得出（自體重型用體重、加負重型用體重＋加掛、輔助型用體重−輔助配重）
4. 只做自體重型一種特例：沒填重量就自動用體重
5. 不知道／先跳過

## 答案
選 3。四種型別：負重型、自體重型、自體重加負重型、輔助型。

## 為什麼
選項 1 讓一整天的引體向上訓練總容量是 0，那個數字比沒有還糟。

選項 2 最省事，而且有個真實優點：使用者自己知道要填什麼。但它讓**輔助引體向上**
沒有出路——輔助配重是「減掉」的，使用者要自己算 70−25＝45 再填進去，
而那正是需求說他們現在在做、想要停止做的事。

選項 4 只解一半：負重引體與輔助引體都還在外面。四種型別是為了讓這四種真實器材
各有一格，不是為了「可擴充」。

代價：需要知道使用者的體重，而需求完全沒提到體重 → `bodyweight-source.md`
