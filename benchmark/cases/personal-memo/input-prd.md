# PRD：個人待辦 App v1.0

**狀態**：已核准
**版本**：1.0
**負責人**：產品部

## 1. 背景

使用者記錄待辦事項的習慣分散在便利貼、通訊軟體的「傳給自己」與手機內建備忘錄之
間，缺乏統一入口。訪談顯示，多數受訪者曾因為「記在別的地方」而漏掉事情。

## 2. 目標

提供個人使用者一個低摩擦的待辦記錄工具，讓想到的事情能在三秒內被記下來。

## 3. 目標使用者

有固定使用手機記事習慣、目前分散在多個工具之間的個人使用者。

## 4. 功能需求

| 編號 | 需求 | 優先級 |
|------|------|--------|
| FR-1 | 使用者可新增一筆待辦，內容為單行文字 | P0 |
| FR-2 | 使用者可將待辦標記為完成 | P0 |
| FR-3 | 完成的待辦應自動從主畫面隱藏 | P0 |
| FR-4 | 使用者可查看本週已完成的待辦清單 | P1 |
| FR-5 | 使用者可調整待辦的排列順序 | P1 |
| FR-6 | 使用者可刪除待辦 | P1 |

## 5. 非功能需求

| 編號 | 需求 |
|------|------|
| NFR-1 | 從開啟 App 到完成一筆新增，操作不超過三秒 |
| NFR-2 | 無網路環境下仍可新增與查看 |

## 6. 不在本次範圍

- 多人協作與分享
- 專案／看板檢視
- 行事曆整合
- 自然語言解析（例如輸入「明天三點開會」自動帶入時間）

## 7. 成功指標

- 上線三個月內日活躍使用者達 3,000
- 使用者平均每日新增 5 筆以上
- 七日留存率高於 35%

## 8. 假設

- 使用者已知道自己要記什麼，App 不需提供範本或建議
- 單一使用者、單一裝置，本期不支援多裝置同步
